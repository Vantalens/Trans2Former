# Trans2Former v2.4.0

状态：稳定化候选，等待 Draft PR CI、人工验收与合并。本文在发布前作为 Release Notes 候选，不代表 GitHub Release 已创建。

## 发布目标

v2.4.0 聚焦现有转换路径的可复验性、状态一致性和发布纪律，不引入新的公共转换 API，也不启动多域模型 Phase 6 迁移。

## 主要变化

- 明确支持 Node.js 22/24，增加 `engines` 与 `.nvmrc`，CI 两版本运行覆盖率门禁。
- 修复版本历史对象变异、历史键快照、审计元数据副作用、修复上下文缺失和输出类型重复状态。
- 更正 #196/#197 的代码注释引用。
- 增加 Worker 重复转换、CSV 尾列和真实浏览器转换矩阵回归测试。
- npm、Cargo、Tauri 和用户可见版本统一为 2.4.0。
- 升级 Express 4、qs、protobufjs 的同主版本安全修复，`npm audit` 为 0 个已知漏洞。

## 重新验证的覆盖率

- Statements / Lines：81.82%（13222/16159）
- Branches：74.62%（3471/4651）
- Functions：86.56%（670/774）

门禁：statements/lines 78%、functions 80%、branches 64%。旧覆盖率报告为历史快照。

## 已验证路径

- Markdown ↔ HTML
- CSV / XLSX → Markdown
- DOCX / PPTX → Markdown
- PDF → TXT
- Markdown → PDF 与二进制下载
- PNG OCR 成功或显式、可操作失败
- Worker 大输入连续转换
- CSV 尾逗号与 CRLF

## 发布前仍需完成

- Draft PR 的 Node 22/24 CI 全部通过。
- Tauri 桌面安装包已构建；仍需安装后启动与交互验收。
- 批量队列取消/重试、历史撤销/恢复、超大文件拒绝的人工浏览器验收。
- PR 合并后关闭或基于证据处置 #181–194、#196、#197；#40、#195、#198 保持非阻塞延期。

Phase 6 仅在 v2.4.0 正式发布后从独立分支开始。
