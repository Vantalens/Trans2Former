## 📚 经验教训

### ✅ 成功模式

1. **缓存 matchAll 结果**: 使用数组展开避免迭代器重复创建
2. **增量更新**: 使用 Map 索引，仅更新变化部分
3. **缓存策略**: 在正确时机失效，懒加载初始化
4. **优先级选择**: 优先修复用户可感知的问题

### ⚠️ 技术挑战

1. **ZIP 解压优化**: 错误检测行为一致性难以保证
2. **文档审核优化**: 警告传递逻辑复杂
3. **权衡取舍**: 性价比评估（DOM 查询懒加载）

### 💡 优化技巧

**迭代器优化模式**:
```javascript
// 修复前：每次循环创建迭代器
for (const match of source.matchAll(pattern)) { }

// 修复后：缓存数组，避免重复创建
const matches = [...source.matchAll(pattern)];
for (const match of matches) { }
```

**增量更新模式**:
```javascript
// 使用 Map 索引现有节点
const existingItems = new Map();
for (const child of listElement.children) {
  existingItems.set(child.dataset.queueId, child);
}
// 复用现有节点，仅更新变化
```

**缓存失效模式**:
```javascript
// 提供更新函数
function updateCachedHistoryKey() {
  cachedHistoryKey = computeExpensiveKey();
}
// 在正确时机调用
inputContent.addEventListener("input", updateCachedHistoryKey);
```
