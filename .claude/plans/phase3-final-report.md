## 💡 根本原因分析

### 为什么覆盖率难以提升？

Trans2Former 是一个**浏览器优先的工具**，核心能力高度依赖浏览器 API：

1. **PDF 处理**: PDF.js（需要 Canvas）
2. **OCR 引擎**: Tesseract.js + ONNX Runtime Web（需要 WebAssembly + Worker）
3. **缓存**: IndexedDB
4. **文件系统**: File System Access API
5. **UI 交互**: DOM + SPA 路由

**结论**: 用 Node.js 单元测试无法覆盖这些模块的核心逻辑。
