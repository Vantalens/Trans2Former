## 🔍 Phase 3 核心发现

### 关键洞察

**70% 的低覆盖率模块依赖浏览器环境**，这是 Trans2Former 作为浏览器优先工具的本质特征：

| 类别 | 模块数 | 占比 | 说明 |
|------|--------|------|------|
| **浏览器专属** | 14 | 70% | 需要 DOM/Canvas/IndexedDB/Worker/ONNX Runtime Web |
| **纯逻辑可测** | 6 | 30% | 可在 Node.js 中完整测试 |

### 浏览器专属模块清单

**P0 级别**（极低覆盖率，< 30%）:
1. pdf-rasterizer-browser.js (6.61%) - Canvas + PDF.js
2. indexeddb-storage.js (16.57%) - IndexedDB
3. router.js (19.9%) - DOM + window + localStorage
4. landing-view.js (28.67%) - DOM 交互

**P1 级别**（低覆盖率，30-70%）:
5. workbench-state.js (40.42%) - 部分 DOM
6. tesseract-runtime.js (49.01%) - Worker + Tesseract.js
7. convert-worker.js (54.54%) - Web Worker API
8. file-queue-ui.js (56.17%) - DOM
9. paddle-ocr-runtime.js (60%) - ONNX Runtime Web
10. paddle-ocr-engine.js (59.77%) - Worker + ONNX
11. ocr-engine.js (65.95%) - 部分浏览器依赖
12. output-directory.js (66.66%) - File System Access API

**P2 级别**（接近达标，70-80%）:
13. pdf-output.js (69.26%) - 部分 Canvas
14. scan-pdf-stage.js (75.43%) - 部分浏览器
